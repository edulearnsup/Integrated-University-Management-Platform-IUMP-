# راهنمای جایگزینی آیکون‌های محلی (`assets/icons`)

آیکون‌های متنی (`<span class="material-symbols-outlined">...</span>`) در صفحات فرود از طریق فایل `icons.css` در همین پوشه بارگذاری می‌شوند.

## فایل مورد انتظار
- `MaterialSymbolsOutlined.woff2`

## نحوه دانلود و جایگزینی
۱. به مخزن رسمی گوگل در گیت‌هاب بروید:
   `google/material-design-icons` -> مسیر `variablefont/`
۲. فایل فونت متغیر زیر را دانلود کنید:
   `MaterialSymbolsOutlined[FILL,GRAD,opsz,wght].woff2`
۳. نام فایل دانلودشده را به **`MaterialSymbolsOutlined.woff2`** تغییر دهید و در همین پوشه (`assets/icons/`) جایگزین کنید.

پس از جایگزینی، تمام آیکون‌های سامانه بدون نیاز به CDN گوگل و کاملاً آفلاین نمایش داده می‌شوند.
